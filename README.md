# StickyPath

**Build consistency. One day at a time.**

StickyPath is a minimalist habit and challenge tracking application built with Flutter. It helps users stay consistent, track their progress, and develop better daily habits through structured challenges.

## Features

- **Challenge Tracking:** Create and follow personal challenges.
- **Multiple Durations:** Choose between 7, 30, 60, 90, 100, and 180-day challenges.
- **Daily Progress:** Mark days as completed or missed.
- **Calendar Tracking:** Visualize your progress and track your consistency.
- **Automatic Missed Days:** Keep your challenge history accurate when days are skipped.
- **Local Storage:** Your data stays on your device.
- **Dark UI:** A clean, minimalist interface designed for everyday use.

## Built With

- Flutter
- Dart
- SharedPreferences
- Local Storage

## Architecture

StickyPath uses a local-first architecture. It does not require user accounts, a backend server, or cloud synchronization.

Challenge data is managed locally through the ChallengeStore.
